# Security Policy

## Supported Versions

Security updates are provided for the latest stable release of Akhtar Agent.

Older versions may not receive security fixes.

## Reporting a Vulnerability

We take the security of Akhtar Agent seriously.

If you discover a security vulnerability, please do not create a public GitHub issue.

Instead, report it privately through GitHub's **Report a vulnerability** feature, if enabled for this repository.

Please include:

- A description of the vulnerability
- Steps to reproduce the issue
- The affected version
- The potential security impact
- Relevant logs or screenshots, with sensitive information removed

## Security Response

We will review security reports and investigate confirmed vulnerabilities.

We aim to acknowledge reports within 7 days, although response times may vary.

Confirmed vulnerabilities will be prioritized based on severity and impact.

## Responsible Disclosure

Please allow reasonable time for investigation and remediation before publicly disclosing a vulnerability.

Do not access other users' data, disrupt services, or test vulnerabilities on systems without permission.

## Scope

Security reports may include vulnerabilities involving:

- AI agent tool execution
- File system permissions
- Terminal command execution
- Browser automation
- API key handling
- Authentication and session management
- Electron application security
- Third-party integrations

## Disclaimer

Akhtar Agent is provided under the Apache License 2.0. Security fixes are provided on a best-effort basis, without a guarantee of immediate remediation.
