# Akhtar Agent — Code of Conduct

## Our Commitment

We are committed to making Akhtar Agent a welcoming, respectful, and inclusive open-source project.

Everyone is welcome to contribute, regardless of experience, background, identity, or skill level.

## Expected Behavior

All community members are expected to:

- Treat others with kindness and respect.
- Provide constructive feedback.
- Respect different opinions and technical approaches.
- Help new contributors learn and improve.
- Respect the privacy and security of others.
- Keep discussions focused on improving Akhtar Agent.

## Unacceptable Behavior

The following behavior is not allowed:

- Harassment, bullying, or discrimination.
- Personal attacks, threats, or intimidation.
- Hate speech or offensive comments targeting individuals or groups.
- Sharing someone's private information without permission.
- Spam, scams, or malicious contributions.
- Deliberately disrupting community discussions.

## Project Security

Contributors must not intentionally introduce malicious code, backdoors, credential stealers, or unauthorized data collection.

Security vulnerabilities should be reported privately according to our SECURITY.md policy.

## Enforcement

Project maintainers may take appropriate action when this Code of Conduct is violated.

Actions may include:

1. A private warning.
2. Removal of inappropriate content.
3. Temporary restrictions on participation.
4. Permanent removal from project spaces.

Enforcement decisions should be fair and proportionate to the situation.

## Reporting Problems

If you experience or witness unacceptable behavior, please contact the project maintainers privately.

Reports will be reviewed with care, and personal information will be shared only when necessary.

## Scope

This Code of Conduct applies to official Akhtar Agent community spaces, including:

- GitHub issues and pull requests
- GitHub discussions
- Official project communication channels
- Other spaces officially managed by the project

## Our Goal

We want Akhtar Agent to be more than an AI application.

We want to build a community where developers can collaborate, learn, and create useful technology together.

**Build responsibly. Contribute respectfully. Innovate together.**
